## Building

**[Shipper](https://github.com/DulsaraNethmin/Shipper)** — Road-transport delivery marketplace connecting customers with providers. Go backend, Flutter app, Next.js admin and driver portals.

**[Minter](https://github.com/DulsaraNethmin/Minter)** — Headless-browser fetch service exposing rendered HTML over an HTTP API. Python, FastAPI, Playwright, Docker.

**[nest-rmq](https://github.com/DulsaraNethmin/nest-rmq)** — RabbitMQ module for NestJS, published to npm as [`@iamnd/nest-rmq`](https://www.npmjs.com/package/@iamnd/nest-rmq).

**[shopware-shopify-integration](https://github.com/DulsaraNethmin/shopware-shopify-integration)** — Sync layer between Shopware and Shopify storefronts. TypeScript.

**[relaxing-shooter](https://github.com/DulsaraNethmin/relaxing-shooter)** — Browser game in TypeScript. [Play it →](https://relaxing-shooter.vercel.app)
